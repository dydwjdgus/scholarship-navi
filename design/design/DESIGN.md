# 장학 내비 — 디자인 명세 (Claude Code 전달용)

이 폴더의 `*.dc.html` 파일은 디자인 툴에서 만든 시안 원본이다. `{{ }}`, `<x-dc>`, `<sc-for>` 같은 전용 문법이 섞여 있으니 **그대로 쓰지 말고 레이아웃·스타일 참고용으로만** 읽는다. 실제 구현은 순수 HTML/CSS/JS로 한다.

## 기술 조건
- 순수 HTML / CSS / JavaScript (프레임워크·빌드 도구 없음)
- PC 화면 기준 (모바일 전용 레이아웃 불필요, 단 깨지지 않을 정도의 유연함은 유지)
- 정적 호스팅(GitHub Pages 등)으로 바로 배포 가능해야 함
- AI 기능 없음, 입력값은 저장하지 않음

## 파일 구조 (제안)
```
index.html      홈
input.html      성적 입력
result.html     결과
css/style.css   공통 스타일
js/data.js      장학금 데이터 (배열) — 나중에 실제 자료로 교체
js/app.js       입력값 처리·기준 비교·결과 렌더링
```
입력값은 `input.html` → `result.html`로 넘길 때 URL 쿼리스트링(또는 sessionStorage)으로 전달한다.

## 화면 1 — 홈 (Main.dc.html)
- 상단 바: 나침반 아이콘 + "장학 내비" 로고, 우측 메뉴(장학금 종류 / 바로 확인하기)
- 히어로: 파란 알약 라벨 "가천대학교 학생을 위한 장학금 길잡이", 56px 굵은 제목 2줄 "내 성적으로 받을 수 있는 / 장학금, 1분이면 알아요", 설명 1줄, 파란 버튼 "내 장학금 찾아보기 →" (input.html로 이동)
- 3단계 카드(성적 입력 → 기준 비교 → 결과 확인), 회색 배경 카드 3개 가로 배치
- "이런 장학금을 확인해요": 교내장학금 / 국가장학금 카드 2개 (아이콘 + 제목 + 설명)
- 푸터: 참고용 안내 문구 + "AI중심세상 팀프로젝트 · [팀 이름]"

## 화면 2 — 성적 입력 (Input.dc.html)
- 가운데 정렬된 폭 560px 단일 컬럼
- "← 처음으로" 링크, 제목 "직전 학기 성적을 / 알려주세요", 안내 "지금은 1학년 기준으로 안내해요. 입력한 정보는 저장되지 않아요."
- 입력 항목 (회색 둥근 입력칸, 높이 60px):
  1. 직전 학기 평점 평균 (숫자, 우측에 "/ 4.5")
  2. 직전 학기 이수학점 (숫자, 우측에 "학점")
  3. 소득구간 (select: 기초·차상위, 1~10구간, 잘 모르겠어요) + 도움말
- 하단 전체폭 파란 버튼 "결과 보기"
- 학년 선택은 없음 (1학년 고정)
- 입력 검증: 평점 0~4.5, 학점 0 이상 정수, 비어 있으면 버튼 비활성 또는 안내

## 화면 3 — 결과 (Result.dc.html)
- 회색(#F2F4F6) 배경, 가운데 폭 720px
- 상단 바 우측에 "다시 입력하기" 버튼
- 요약 카드: "받을 수 있는 장학금이 N개 있어요"(N은 파란색), 입력값 칩(평점 / 학점 / 소득구간), 개수 박스 3개(기준 충족 / 조금 부족 / 해당 없음)
- 섹션 3개로 장학금 카드 나열:
  - **기준을 충족했어요**: 교내/국가 태그, 장학금명, 우측 "✓ 충족" 파란 배지, 기준별 줄(항목명 ↔ "기준 이상 · 충족"), 하단에 지원 금액 + "신청 방법 보기" 링크
  - **조금만 더 하면 받을 수 있어요**: 주황 "! 조금 부족" 배지, 부족한 항목은 주황 글씨로 "평점 0.20 부족", 하단 회색 박스에 목표 안내
  - **이번엔 해당되지 않아요**: 한 줄짜리 간단한 카드(태그 + 이름 + 사유)
- "조금 부족" 판정 기준: 평점이 기준보다 0.3 이하로 모자라거나 학점이 3학점 이하로 모자랄 때 (값은 data.js에서 조정 가능하게)
- 하단 참고용 안내 문구

## 데이터 (js/data.js)
아직 실제 자료가 없으므로 예시 3~4개로 채우고, 이름 뒤에 "(예시)"를 붙인다. 형식 예:
```js
const SCHOLARSHIPS = [
  { name: "국가장학금 Ⅰ유형 (예시)", type: "국가", minGpa: 0, minCredits: 0, maxIncome: 8, amount: "자료 확인 후 입력", link: "#" },
  { name: "학업장려장학금 (예시)", type: "교내", minGpa: 0, minCredits: 0, maxIncome: null, amount: "자료 확인 후 입력", link: "#" },
];
```
(기준값 0은 자리표시 — 자료수집 담당 자료가 오면 이 파일만 수정)
소득구간은 기초·차상위 = 0, 1~10구간 = 1~10, 모름 = null 로 다루고, 모름이면 소득 기준이 있는 장학금은 "소득구간 확인 필요"로 표시.
